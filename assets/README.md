# Release assets

Before any EAS build, add reviewed production assets here:

- `icon.png`: square 1024×1024 PNG with no transparency requirements unresolved.
- `adaptive-icon.png`: Android foreground artwork with a safe-area margin.
- `splash.png`: reviewed splash artwork for the configured light theme.
- `notification-icon.png`: monochrome Android notification icon.

These are intentionally not fabricated placeholders. Their absence is a release blocker.
