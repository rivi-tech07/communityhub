Logical names requested by the product are mapped to the actual relation names in the Notes column.

## Follow-ups

No unresolved matrix cells remain. `N/A` means no administrator write workflow exists in the current application; adding one requires a protected server route, authorization tests, and a new matrix entry.

The `order_items` service-only classification is implemented by `202610260012_order_items_service_only.sql`; the authenticated API route still validates the caller and computes product prices before using the server-only client for persistence.

The coverage check itself is in `supabase/tests/rls_coverage.sql` and is exposed to the conditional integration test through the service-role-only `check_public_rls_coverage()` function. The allowlist currently contains only `spatial_ref_sys`, an extension-owned infrastructure relation; adding another name requires a security review and a note here.
