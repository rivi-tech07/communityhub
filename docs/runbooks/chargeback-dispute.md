# Chargeback and dispute runbook

| Field                           | Procedure                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Symptom                         | Stripe or Razorpay reports a dispute, chargeback, retrieval request, or evidence deadline.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Impact                          | Funds may be reversed and a missed evidence deadline can make the loss final.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Detection                       | **requires provider console**: monitor Stripe Disputes and Razorpay Chargebacks/Disputes; correlate the payment ID with `payment_transactions` and webhook IDs in `payment_events`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Immediate mitigation            | Freeze fulfilment/refund automation for the affected transaction, preserve the original order, delivery proofs, customer messages, terms, refund history, and signed webhook payload. Do not delete evidence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Root cause investigation        | Identify dispute reason, notification time, provider deadline, merchant-of-record responsibility, delivery status, refund status, and whether the customer was already refunded.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Recovery steps (exact commands) | Export a redacted ledger record: `curl -sS "$SUPABASE_URL/rest/v1/payment_transactions?id=eq.$TRANSACTION_ID&select=id,provider,provider_payment_id,provider_order_id,status,amount_minor,currency,refund_amount_minor,created_at" -H "apikey: $SUPABASE_SERVICE_ROLE_KEY" -H "Authorization: Bearer $SUPABASE_SERVICE_ROLE_KEY"`. Assemble the evidence pack and submit it in the provider portal: **requires provider console**. Stripe evidence must be submitted by the deadline shown on the dispute; Stripe does not provide one universal deadline in this runbook. Razorpay terms state chargeback documents are due within 3 calendar days of notification, or another period specified by the facility provider; use the dashboard deadline as authoritative. |
| Post-incident actions           | Record the provider case ID, submitted evidence, decision, fees, and customer outcome. Update support and finance controls; add a regression test or monitoring rule for the root cause.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Owner                           | Payments, support, and finance on-call; legal/compliance for contested liability.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

Provider deadlines are authoritative over this document. Stripe evidence is submitted through the Dashboard/API; Razorpay chargeback evidence is submitted through the Razorpay workflow. Both paths **require provider console** access.

Provider references: [Stripe disputes](https://docs.stripe.com/api/disputes) and [Razorpay terms, chargeback documents](https://razorpay.com/terms/).
