# Payment reconciliation runbook

| Field                           | Procedure                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Symptom                         | Provider settlement totals do not match `payment_transactions`, or a payment appears paid twice, missing, refunded, or in the wrong currency.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Impact                          | Financial reporting, customer balances, fulfilment, or payouts may be incorrect.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Detection                       | Daily compare provider settlement reports with `payment_transactions` grouped by provider, currency, status, and settlement date. **requires provider console**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Immediate mitigation            | Stop fulfilment for unmatched payments and keep `PAYMENTS_LIVE_ENABLED=false` during an incident. Do not create a second charge to “fix” a missing webhook.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Root cause investigation        | Compare provider payment/refund IDs, `amount_minor`, `currency`, `status`, `refund_amount_minor`, `payment_events`, webhook delivery attempts, and transaction `idempotency_key`. Check timezone and settlement cutoffs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Recovery steps (exact commands) | Run stock checks separately with `SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... pnpm reconcile:stock`. For payments, export ledger rows: `curl -sS "$SUPABASE_URL/rest/v1/payment_transactions?select=id,provider,provider_payment_id,provider_order_id,amount_minor,currency,status,refund_amount_minor,created_at,updated_at" -H "apikey: $SUPABASE_SERVICE_ROLE_KEY" -H "Authorization: Bearer $SUPABASE_SERVICE_ROLE_KEY" > /tmp/payment-ledger.json`; download the matching settlement report: **requires provider console**; join on provider payment/order ID and investigate every difference. For a missing event, use [webhook-replay](webhook-replay.md). For a provider-side refund, use [refund](refund.md). Never insert a replacement transaction for an existing provider payment. |
| Post-incident actions           | Save the reconciliation report, unmatched-item decisions, provider case IDs, and corrected ledger state. Add monitoring for the failure class and retain the provider settlement export under the approved finance retention policy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Owner                           | Finance and payments on-call.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

The source of truth for application money state is `payment_transactions` plus verified `payment_events`; provider settlement reports are the external control total.
